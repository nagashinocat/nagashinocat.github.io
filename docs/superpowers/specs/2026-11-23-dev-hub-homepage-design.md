# 開発置き場ホームページ 設計書

2026-11-23 / 公開先: nagashinocat.github.io（GitHub Pages のユーザーサイト）

## 1. 目的・なぜ作るか
- nagashinocat の「いい感じの自分のホームページ」兼「開発置き場」。
- 来た人がすぐゲームを遊べる入口であり、ゲーム以外（南海トラフ地震シミュレーター、いつか公開する3D読み込みツール等）も同じ場所に置ける。
- 作品が増え続けるので、置き場所（街のどこに建てるか）を決めて足していける作り。

## 2. 目標 / 目標でないこと / 失敗とみなすこと
- 目標: 開いた瞬間に「なんだこれ、いい」と思わせる飛び出す絵本の街。目当てのゲームに2タップで着く。
- 目標でないこと: サーバー、ログイン、ランキング、ブログ機能。
- 失敗: 重くてスマホで開かない／ゲームにたどり着けない／作品追加のたびに大改造が要る。

## 3. 本人が決めたこと（そのとおりに作る）
- **飛び出す絵本**: 最初に本が開き、ページから建物がにょきにょき生えてくる。2D（紙っぽい絵）と3Dを混ぜる。
- **ページをめくる**と街区が変わる:
  1. ネオンの繁華街 … ゲーム
  2. ボロい工場街（錆びトタン・煙突の町工場） … 道具（南海トラフ、3D読み込みツール等）
  3. 工事中の空き地 … 開発中の作品
- **テーマ**: 「最後の一撃」の九龍城×日本のネオン街。あれより作り込んで、もっとゴチャゴチャ。
- **主役の電光掲示板ビル**をいちばん目立つ場所に置く。
- **街のあちこちの看板＝ゲームタイトル**。カーソルを合わせると、電光掲示板にタイトル・プレイ映像・CMが流れる。
- 作り方は **A案**: Three.js の3D空間に、コード（canvas）で描いた紙の建物を立てる。気に入った建物だけ後から自分の絵に差し替えられる。

## 3.5 見た目の基準（本人のスクリーンショットより）
- 「最後の一撃」の色: 夕暮れのオレンジ〜紫〜群青の空、暖かい黄色の窓の格子、建物の縁のピンク・水色のネオン線、白く光る高速道路と車のライトの帯。
- 本人の追加要望: **建物と街並みの正確さはもっと細かく、漫画調に**。
  - 黒い墨の輪郭線、スクリーントーン（網点）の影、カケアミ・斜線の陰影。
  - 窓枠・手すり・室外機・配管・看板の文字まで描き込んだ密度。
  - **何に使っているかわからないチューブやダクトを大量に**這わせる（壁を伝う、ビル間をまたぐ、束になって垂れる、途中で途切れる）。
  - 色は上記の夕暮れネオンの配色を、漫画のベタ塗り＋トーンで表現する。
- whale-watch（クジラが見てる）は繁華街に置く。

## 4. 提案として出し、否定されていないこと
- スマホ: 1回タップで電光掲示板に流れる、もう1回タップ（または掲示板の「あそぶ」）で遊べる。
- 何も選んでいないとき、掲示板はオレンジのドット文字で作品タイトルを順に流す。新作は「NEW」付きで先に流れる。
- CMは既存の宣伝動画を使う（while it's raining／超能力者の証明／猫ちゃん）。動画がない作品はタイトル＋画面写真＋一言。
- すぐ遊びたい人向けに、街を使わない「作品一覧」への近道を置く（3Dが動かない端末の逃げ道も兼ねる）。

## 6. 体験の流れ
1. 読み込み: 暗い机の上に閉じた本。ネオンの光が表紙の隙間から漏れる。
2. 本が開く → 建物が手前から奥へ時間差でにょきにょき起き上がる（紙が折り目から立つ動き）。最後に電光掲示板ビルが点灯。
3. 見回す: 指／マウスで少しだけ視点を振れる（ぐるぐる回しすぎない。本の上を覗き込む範囲）。
4. 看板に触れる → 看板が光る＋掲示板がその作品のCMに切り替わる → 「あそぶ」で作品へ。
5. ページの端をめくる → 建物が倒れて畳まれ、次の見開きで次の街区が生える。

## 7. 作りの方針
- Three.js（バージョン固定、CDN読み込み）。サーバーなし、GitHub Pages で静的配信。
- 建物はすべて canvas で描いたテクスチャを貼った板（紙の切り絵）。窓・看板・配管・室外機・洗濯物・電線などの部品を組み合わせて自動生成し、毎回同じ見た目になるよう乱数の種を固定。
- 光: ネオン・掲示板は発光表現（ブルーム）。重い端末では自動で弱める。
- 縦画面スマホとPCの両方。スマホで軽く動くことを最優先。
- 動画はページ内で再生（音なし自動再生、タップで音あり）。

## 7.5 こちらで決めたこと（本人が確認するもの）
- **掲示板は各ページに1つ**、街区に合わせた姿にする。繁華街はネオンの電光掲示板ビル、工場街は古いブラウン管モニターを積み上げた塊、空き地は工事現場の電光表示板。
- **作品ではない飾り看板もたくさん置く**（ゴチャゴチャのため）。作品の看板だけ、ゆっくり明滅して小さな「▶」がつくので見分けられる。
- **掲示板の画面は縦長でも横長でも映せる**ように、縦長のタワー型画面にする。横長の動画は上下に余白を入れ、走るドット文字を置く。動画はスマホ用に軽く作り直す。
- **後から差し替える絵は、背景が透明なPNG**を想定する。建物データに「差し替え画像」欄を最初から用意しておく。
- 公開先リポジトリ: **nagashinocat/nagashinocat.github.io**（作成済み、名前の修正済み）。

## 8. 作る人に任せること
- 建物の部品の描き方、配置の細部、色の具体値、アニメの時間配分。
- 本・ページめくりの3D表現の実装方法。
- 作品一覧の近道の見た目。

## 9. 方法の比較（決定済み）
- **A（採用）** Three.js＋コードで描いた紙の建物: 絵の用意が要らずゴチャゴチャを量産でき、光もきれい。後から自作絵に差し替え可。
- B 自分で用意した絵を3D空間に立てる: 質感は最高だが大量の絵が要る。
- C ライブラリなし（ウェブページの機能だけ）: 最軽量だが光と奥行きが弱く密度が出ない。
